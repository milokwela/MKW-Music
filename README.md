## Что такое MKW Music

MKW Music — музыкальный веб-плеер для телефона и компьютера. Он открывается в браузере и устанавливается как обычное приложение: значок на экране, полноэкранный режим, без магазина приложений. Все обновления и разработку делает **MiloKwel**.

## Возможности

| | Возможность | Что умеет |
|---|---|---|
| 🌊 | **MKW Волна** | Бесконечный поток музыки под ваш вкус: учитывает лайки и историю, реагирует на пропуски и дослушивания, открывает новых исполнителей из любимых жанров |
| 🎤 | **Текст песни** | Строки идут в такт музыке, спетые слова светятся цветом акцента, соседние строки размыты. Источники: LRCLIB, NetEase, Genius, lyrics.ovh. Работает и в Волне |
| 🔍 | **Поиск** | iTunes, YouTube, Audius и поиск по ссылке. Источник выбирается в Профиле |
| 🎧 | **Шазам** | Узнать песню с микрофона или из файла |
| 👤 | **Профиль** | Свой баннер и фото, статус, рамка, закреплённые значки, витрина: до 4 любимых исполнителей и до 10 треков |
| 🏆 | **Слушатели** | Рейтинг по времени прослушивания. Профиль любого слушателя можно открыть |
| 🏅 | **Достижения** | 23 награды с полосками прогресса |
| 🎙️ | **Исполнители** | Страница с фото, числом поклонников, справкой из Википедии и популярными треками |
| ✋ | **Жесты** | Девять жестов камерой. Камера работает на вашем устройстве, изображение никуда не передаётся |
| 🎨 | **Оформление** | Material 3 и «жидкое стекло». Темы: авто, светлая, тёмная, чёрная, любой свой цвет акцента |
| ⚡ | **Слабые устройства** | Режим оптимизации отключает размытие и тяжёлые анимации |

## Как начать

1. Откройте **[mkwmusic.ru](https://mkwmusic.ru)**
2. Зарегистрируйтесь: нужны только ник и пароль, почта не нужна
3. Нажмите «Установить приложение» — значок появится на экране

> **Из России без VPN** часть музыкальных серверов может не открываться (провайдеры блокируют превью и обложки). Если нет звука — включите любой VPN.

## Для разработчика

### Структура

Сайт без сборки: HTML, CSS и ES-модули лежат в корне репозитория и публикуются через GitHub Pages.

| Файл | Зачем |
|---|---|
| `index.html` | Разметка, заставка, иконки SVG |
| `app.js` | Запуск, навигация, вход |
| `player.js`, `playerui.js` | Плеер и полноэкранный экран |
| `lyrics.js` | Текст песни в реальном времени |
| `profile.js`, `userpage.js`, `leaders.js` | Профиль, страница слушателя, рейтинг |
| `artist.js`, `artistpic.js` | Страница исполнителя и его фото |
| `icons2.js` | Иконки Material 3 (рисованные SVG) |
| `motion.js` | Переходы и волна при нажатии |
| `firebase.js`, `store.js` | Firebase и данные пользователя |
| `firestore.rules` | Правила базы данных |
| `docs/recognize-worker.js` | Код Cloudflare Worker |

### Файлы с ключами (не перезаписывать при обновлении)

`firebase-config.js`, `keys.js`, `config.js`, `shazam-config.js` — у каждого свои значения. В обновлениях их нет.

### Firebase (бесплатный тариф Spark)

1. **Authentication → Sign-in method → Email/Password** — включено (ник превращается во внутренний адрес `ник@mkw.invalid`, почта не нужна).
2. **Firestore Database → Rules** — вставьте содержимое [`firestore.rules`](firestore.rules) и нажмите **Publish**. Без этого не работают рейтинг и профили слушателей.
3. **Authentication → Settings → Authorized domains** — добавьте `mkwmusic.ru`.

Что сделано, чтобы уложиться в бесплатный лимит (50 000 чтений и 20 000 записей в день):
- локальный кэш Firestore в IndexedDB — повторные открытия почти не тратят чтения;
- рейтинг пишется не чаще раза в 3 минуты, страница профиля — только при изменениях и раз в 15 минут;
- правила проверяют размер и поля каждого документа, чужие данные менять нельзя.

### Cloudflare Worker

Один Worker отвечает за всё серверное, ключи хранятся только в Cloudflare:

| Адрес | Что делает |
|---|---|
| `POST /` | Распознавание песни (ACRCloud или AudD) |
| `GET /lyrics` | Текст песни: NetEase (с таймингами) и Genius |
| `GET /artist` | Фото исполнителя и число поклонников (Deezer) |
| `GET /geo` | Страна подключения |
| `GET /ping` | Проверка, что Worker обновлён |

Как обновить: Cloudflare → Workers → `mkw-recognize` → **Edit code** → вставить [`docs/recognize-worker.js`](docs/recognize-worker.js) → **Deploy**.
Переменные: `ALLOWED_ORIGIN`, `ACR_HOST`, `ACR_KEY`, `ACR_SECRET` (или `AUDD_TOKEN`).
